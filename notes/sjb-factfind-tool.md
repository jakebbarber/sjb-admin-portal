- **PDF text extraction, done properly (25 Aug 2026, build 13:26)** — three real bugs, all found on the user's own documents. (1) **Never trust `/Length`**: it is often an indirect reference (`/Length 12 0 R`), so reading the digits after it truncates the stream — a 51-page Aon quotation gave 5 lines instead of 268. Scan to `endstream`, trim the trailing EOL, inflate (try `deflate` then `deflate-raw`). (2) **CID fonts**: modern PDFs encode text as glyph numbers (`<003D>`) with a **ToUnicode CMap** giving the meaning. `pdfCMap()` merges every `beginbfchar`/`beginbfrange` block in the file, and the hex branch decodes 4-hex-digit codes through it; the `unmapped` ratio is returned so a font with no map shows up rather than producing silent nonsense. (3) **`pdfFurnitureOnly()`** — a pack can carry a text layer that is *only* the address block and "Page 3 of 51" footers, with the entire quotation as page images; without this test it looks identical to a bug. The UI now says "The pages are pictures" and points at the OCR script. Verified: Aon quotation 268 lines / 0% unmapped / thin=true; a CashCalc PDF 709 lines; the synthetic LOA 21/23 fields; a scanned TVQ still `scanned=true`.

- **OCR quality — resolution, and never trusting the reader (25 Aug 2026, build 14:36)** — the first real run came back with `"Ni A as nein A fief Bs een SEs das rma men Te me Tarai se i"` sitting in a MADS field. Two causes. (1) **Render resolution**: pages were going to Tesseract at `scale 2.2` = **158 dpi**; Tesseract wants **300 dpi** and invents words below ~200. A PDF point is 1/72", so the scale is now computed as `300/72` (≈4.2×) with a pixel cap (4400×6200) for memory. **Never pick an OCR render scale by eye — compute it from dpi.** (2) **The extractor accepted the noise.** `fieldOk` now applies `looksLikeProse()` to every text/long answer: rejects when >40% of words are 1–2 letters, >25% of words over 2 letters have no vowel, or letters are <45% of the string; strings of under 3 words pass untouched so "GBP", "AV-118822", "0.85%" still work.
